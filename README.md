## Claude Code mods

Small plugins that add live panes, status lines and toasts to Claude Code. Clawd stars in most of them.

| Mod | What it does |
|---|---|
| [clawd-spinner](https://github.com/saiharsha03/clawd-spinner) | Clawd acts out all 189 spinner words. Nothing leaves your machine. |
| [pomodawd](https://github.com/saiharsha03/pomodawd) | Focus timer: Clawd works at a desk for 25 minutes, then naps in a hammock for 5. |
| [clawd-pet](https://github.com/saiharsha03/clawd-pet) | A pet that's fed by clean turns and made sick by failed tool calls. |
| [tool-radar](https://github.com/saiharsha03/tool-radar) | A radar of this session's tool calls, one blip per call. |
| [diff-garden](https://github.com/saiharsha03/diff-garden) | Every edited file is a plant: added lines grow it, untested edits wilt it. |
| [context-aquarium](https://github.com/saiharsha03/context-aquarium) | The context window as a fish tank that murks as compaction nears. |
| [clawd-commute](https://github.com/saiharsha03/clawd-commute) | Your git branch as a tram line; a push makes the tram depart. |
| [night-shift](https://github.com/saiharsha03/night-shift) | Clawd's office follows your clock, from sunrise to a desk lamp at night. |
| [test-arena](https://github.com/saiharsha03/test-arena) | Green tests kill monsters; red ones fight back. |
| [streaks](https://github.com/saiharsha03/streaks) | A heatmap of the days you used Claude Code. |
| [rate-barometer](https://github.com/saiharsha03/rate-barometer) | A weather glyph that goes from sun to storm as your usage limit fills. |
| [verb-toasts](https://github.com/saiharsha03/verb-toasts) | One end-of-turn toast: files read, files edited, test runs, elapsed. |
| [fortune-clawd](https://github.com/saiharsha03/fortune-clawd) | A Claude Code tip when a session starts. |
